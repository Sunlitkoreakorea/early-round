# 얼리 플랜

커먼앱 얼리 지원(ED, EA, REA, SCEA, ED2) 대학 정리 사이트.

- 학교: 목록에서 골라 얼리 방식, 마감, 얼리 규칙, 국제학생 재정지원, 시험, 보충 에세이, 인지과학 전공 확인. 지원 방식 선택, 할 일, 메모.
- 전략: 고른 방식을 칸별로 모아 같이 못 쓰는 조합(ED 두 곳, REA/SCEA + 다른 사립 얼리 등)을 표시.
- 달력: 마감, 재정 서류, 발표 일정.

내 선택과 메모는 브라우저(localStorage)에만 저장되고, 메뉴에서 JSON 백업/불러오기.

## 학교 자료

- `tools/raw/*.json`: 학교별 공식 입학처 페이지 확인 결과 (2026-27 시즌, 2026-11-25 확인).
- `python tools/build_data.py` 로 `data.js` 생성. 손으로 고칠 값은 스크립트의 `FIX`.
- 날짜는 2026-27 시즌 것을 1년 뒤로 옮겨 보여 줌. 2027년 8월 커먼앱이 열리면 새 시즌 날짜로 다시 확인할 것.
