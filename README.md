# 얼리 플랜

미국 대학 얼리 지원(ED, EA, REA, SCEA, ED2) 정리 사이트. 탭 6개:

- 학교: 얼리 방식과 마감, 얼리 규칙, 가능성(규칙 기반 5단계와 이유), 합격 통계(CDS), SAT 범위와 점수 낼지, 국제학생 재정지원, 보충 에세이, 서류 체크, 메모.
- 지도: 미국 전체 + 동북부 확대 (d3-geo, us-atlas 를 지도 탭을 열 때 CDN 에서 불러옴).
- 전략: 같이 못 쓰는 얼리 조합 검사, 칸별 카드, 리스트 균형, 12월 시나리오(쓸 수 있는 ED2), ED 고르기 비교.
- 일정: 로드맵(SAT/AP 날짜는 College Board 확인, 추천 시기, 내 일정) + 학교 마감 달력.
- 지원서: 커먼앱 활동 10칸(50/100/150자), 수상 5칸(100자), 본 에세이와 추가 정보(650단어), 보충 에세이 모아보기, MIT/UC 형식.
- 나: SAT(지금/목표), 재정지원 필요, AP, GPA, 학교별 가능성 한눈에.

기록은 브라우저(localStorage `early-round-v1`)에만 저장. 메뉴에서 JSON 백업/불러오기.
`private/my-profile.json`(저장소 제외)은 개인 정보로 미리 채운 불러오기 파일.

## 학교 자료

- `tools/raw/schools-*.json`: 얼리 방식, 마감, 규칙, 재정지원 (2026-27 시즌, 2026-11-25 확인)
- `tools/raw/stats-*.json`: 합격 통계, 주로 Common Data Set 2025-26 (2026-11-26)
- `tools/raw/req-*.json`: 추천서, 보충 에세이(질문은 요약), 원서비, CSS 코드 (2026-11-26)
- `tools/raw/verify-*.json`: 다른 에이전트가 출처와 다시 대조한 결과(정정, 보충, 학교별 확인 상태)
- `python tools/build_data.py` 로 `data.js` 생성. 손으로 고칠 값은 `FIX`, `STATS_FIX`, `STATS_PATCH`, `REQ_FIX`.
- 날짜는 2026-27 시즌 것을 1년 뒤로 옮겨 표시. 2027년 8월 커먼앱이 열리면 새 시즌으로 다시 확인할 것.
